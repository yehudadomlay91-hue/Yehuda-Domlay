# Portal Layanan Akademik

Website contoh untuk latihan HTML, CSS responsif, dan aksesibilitas.

## Isi folder

- `index.html` — struktur halaman, kartu layanan, formulir, dan JavaScript validasi demo.
- `styles.css` — tampilan dan tata letak responsif dengan tema merah.
- `README.md` — petunjuk menjalankan proyek.

## Cara menjalankan

1. Ekstrak file ZIP ini.
2. Pastikan `index.html` dan `styles.css` berada di folder yang sama.
3. Buka `index.html` menggunakan browser seperti Google Chrome atau Microsoft Edge.
4. Untuk mengedit kode, buka folder tersebut menggunakan Visual Studio Code.

## Fitur

- Navigasi semantik: `header`, `nav`, `main`, `section`, `article`, dan `footer`.
- Enam kartu layanan akademik.
- Formulir dengan kolom wajib dan validasi HTML.
- Tata letak responsif untuk layar ponsel, tablet, dan desktop.
- Tautan lewati ke konten utama dan indikator fokus keyboard.
- Tema warna merah dan putih.

## Catatan penting

Formulir ini hanya demonstrasi di sisi browser. Tombol **Periksa permohonan** memvalidasi input, tetapi data tidak dikirim atau disimpan ke server. Untuk menerima permohonan sungguhan, proyek perlu dihubungkan ke backend.
